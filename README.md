
### 主要类说明

- **MoneyTipPlugin.kt**：插件主入口，负责初始化和调度定时任务
- **MoneyTipConfigurable.kt**：配置界面实现
- **MoneyTipStatusBarWidget.kt**：状态栏组件
- **DocumentChangeListener.kt**：文档变更监听器，处理打字和删行事件
- **PluginConfig.kt**：插件配置数据模型
- **TimeUtil.kt**：时间工具类
- **StockUtil.kt**：股票数据工具类

### 构建项目

1. 克隆项目：`git clone <repository-url>`
2. 打开IntelliJ IDEA并导入项目
3. 运行 `gradlew build` 构建项目
4. 在 `build/libs/` 目录下找到生成的jar文件
